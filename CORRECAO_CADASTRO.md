# Correção de cadastro — StudyFlow V9

- Após salvar atividade ou sessão, a janela é fechada antes da atualização dos componentes.
- O botão de salvar é desabilitado durante o envio e há proteção contra cliques repetidos.
- Os dados continuam armazenados localmente, como na versão anterior.
- Se já existem registros duplicados, exclua-os em **Minhas atividades** ou **Meu cronograma**; a correção evita novos envios repetidos, não apaga registros anteriores.
- Para atualizar um site publicado, publique o conteúdo desta pasta novamente. Se necessário, atualize com Ctrl+F5.
