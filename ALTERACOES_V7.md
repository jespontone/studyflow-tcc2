# StudyFlow V7 — alterações de interface

1. Logo original substituída pela ilustração PNG `mascote-studyflow.png`.
2. Banner principal utiliza o gato transparente na frente de um cartão e atrás de outro. As estrelas decorativas da camada frontal foram removidas; o fundo mantém elementos discretos.
3. Paleta de destaque: azul #0953F5, amarelo #FFD058, rosa #FF97A4, bege #FFF3D9.
4. Perfil do estudante com contraste ajustado. Para mostrar nome/instituição, preencha e salve a página Meu perfil acadêmico.
5. Números dos indicadores no modo escuro e calendário com texto reforçado em ambos os temas.
6. Rodapé “Continue firme!” sem fotografia.

Estilos adicionais estão em `v7.css`, carregado após `v6.css`. Para publicar, envie todo o conteúdo da pasta em uma hospedagem estática. O botão do Google Forms usa `form-config.js`. As funções da API requerem servidor Node.js separado.
