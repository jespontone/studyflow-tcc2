# StudyFlow V13 — Perfil visual

- Clicar no avatar/nome no rodapé do menu abre o perfil acadêmico.
- Quem já tem dados salvos vê um cartão com foto, nome, universidade, curso, semestre, disciplinas e disponibilidade.
- **Editar perfil** abre o formulário anterior, incluindo o gerador de cronograma.
- Ao salvar, volta para a visualização do perfil.
- Para usuários sem cadastro, o formulário abre diretamente.
- Não foi acrescentado cadastro de múltiplos perfis porque o armazenamento atual é local e compartilhado no mesmo navegador.
